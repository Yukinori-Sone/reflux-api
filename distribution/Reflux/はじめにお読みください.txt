Reflux（カスタム版）
==================

beatmania IIDX INFINITAS のプレー記録・自己ベストを読み取って保存するツールです。
本家 olji/Reflux（https://github.com/olji/Reflux）に、別のPCから記録を見るための API などを足したものです。
ゲームのメモリは読むだけで、書き換えは一切しません。

■ 動かし方
1. このフォルダを好きな場所に置きます（例: C:\Reflux）。
   C:\Program Files の下は書き込みに管理者権限が要るので避けてください。
2. Reflux.exe を起動します。INFINITAS より先に起動しておいても大丈夫です（起動を待ちます）。
   .NET のインストールは要りません。
3. 記録は sessions フォルダ、自己ベストは tracker.db / tracker.tsv に保存されます。

■ Windows の起動時に自動で動かすとき（どちらか一方）
・サービスにする（おすすめ）: Service-Install.bat を右クリックして「管理者として実行」します。
  「Reflux API Server」というサービスになり、Windows の起動時に自動で開始し、窓は出ません。
  止まったときは自動で起動し直します。やめるときは Service-UnInstall.bat を同じく管理者として実行します。
・スタートアップに置く: Reflux.exe のショートカットをスタートアップフォルダ
  （エクスプローラーのアドレス欄に shell:startup と入力）に置きます。窓が出ます。
同じフォルダの Reflux は1つしか動きません（両方にしても、あとから起動した方は終了します）。

■ タスクトレイの管理ツール（RefluxAPIManager.exe）
サービスにすると窓が出ないので、状態の確認と設定の変更は Reflux API Manager で行います。
リザルト画面のスクリーンショットも Reflux API Manager が撮ります（Reflux.exe と同じフォルダに置いたまま使います）。
Service-Install.bat の最後に自動で起動し、次からはログオン時に起動します（右クリックのメニューで切り替えられます）。
・アイコンの色: 緑 = 監視中、黄 = INFINITAS 待ち、赤 = エラー・サービス停止、灰 = サービス未登録
・左クリック: 状態ウィンドウ（INFINITAS の状態、INFINITAS ID、直近のプレー、エラーの記録など）
・右クリック: 設定、Reflux API サービスの開始・停止・再起動、フォルダを開く
・設定画面のタブ
  API              … API の有効・公開範囲・ポート・APIキー（「生成」で作ってクリップボードにコピー）。保存するとサービスを再起動
  スクリーンショット … 撮るかどうか、形式、どのリザルトを残すか（screenshots フォルダに保存）
  動作設定          … 配信用・最新プレーのファイル出力、監視間隔など（その場で反映）
設定は RefluxAPIManager.json に保存します（このフォルダに書き込めないときは %LOCALAPPDATA%\RefluxAPIManager）。

■ 初期設定について
このカスタム版は、記録をクライアント（API）で見ることを前提にしているため、
配信用のファイル（latest.txt、playstate.txt、marquee.txt、title.txt など）は出力しない設定にしています。
配信で使うときは config.ini の [Record] savelatestjson / savelatesttxt と [Livestream] の各項目を true にしてください
（Reflux API Manager の設定画面からも変えられます。その場で反映します）。

■ クライアント（記録を見るツール）から見るとき
config.ini の [Api] は最初から enabled = true です（同じ PC からだけ見られる host = localhost）。
別の PC から見るときは、次のようにします。
  host = localhost   … 同じPCのクライアントからだけ見るとき
  host = +           … LAN の別PCから見るとき（下の準備が必要）
  apikey = 好きな文字列（クライアントにも同じものを入れます）

host = + にするときは、一度だけ管理者のコマンドプロンプトで次を実行し、
ファイアウォールでポート 8790（TCP の受信）を許可してください。
  netsh http add urlacl url=http://+:8790/ user=<Windowsのユーザー名>
（サービスで動かしている場合、netsh の手順は不要です。ファイアウォールの許可だけ必要です）

■ 更新するとき
サービスで動かしている場合は、先にサービスを止めてください（管理者のコマンドプロンプトで sc stop RefluxAPIServer、
終わったら sc start RefluxAPIServer）。
新しい版の中身をこのフォルダに上書きしてください。ただし config.ini は上書きしないでください
（設定が初期値に戻ります）。記録のファイル（tracker.db、sessions、plays.jsonl など）は配布物に入っていないので、
上書きしても消えません。
