独自機能の追加（API・クライアント等）はここには書かない。

- 本家の更新を取り込むときは、ここにある修正と本家側の変更がぶつからないか確認する（本家が同じ不具合を直していれば、こちらの修正は不要になる）
- 「対象バージョン」は事象を確認した Reflux のバージョン（`Reflux/Reflux.csproj` の `<Version>`）と、そのときの本家のコミット
- 本家へ報告・PR したら「本家への報告」欄に書く
